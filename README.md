# Hearth: a household budget site

A small, friendly budget tracker for a family. Plain HTML, CSS and JavaScript. No build step, no network requests.

**What it does:** dashboard with balance, income, spending and savings rate; add, edit and delete transactions; eight categories with icons and colors; month switcher with last-month comparison; monthly budget limits with over-budget warnings; savings goals; donut and 6-month bar charts; search, filters and CSV export. Data is saved in your browser (localStorage) and starts with sample family data.

**How to open it:** double-click `app/index.html`, or run `node main.ts` first to regenerate `app/` from `src/` (Node 22).
